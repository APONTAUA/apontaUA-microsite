## ApontaUA API

| Property | Value |
|---|---|
| Status | Pending backend integration |
| API framework | FastAPI (planned) |
| API description | OpenAPI, generated by the backend when available |
| Data store | PostgreSQL (planned) |
| Architecture | Modular monolith |

The microsite repository does not contain a backend application or an OpenAPI specification. Endpoint names, request and response schemas, examples, and downloadable specifications will be documented from the real FastAPI OpenAPI output once that source is available.

:::note[No endpoints published]
There are no API operations to display yet. This page will be populated from the application specification; no sample endpoints are presented as if they were implemented.
:::

## Planned reference structure

When the OpenAPI source is integrated, the reference will organize real operations by category and show their HTTP method, path, description, parameters, request body, responses and schemas. The specification download and interactive examples will depend on the backend's published OpenAPI document.
