## Activity Plan

> **Planning note:** This activity calendar is being consolidated as part of the ApontaUA project-management restructuring associated with Milestone 3 (MS3). The team recognizes that iteration-level planning, task ownership and expected deliverables should have been organized and tracked consistently during the previous iterations. This calendar formalizes that practice, bringing together the work plan that was previously scattered across project-management documents. It should be used as the reference for coordinating and monitoring the remaining work.
